# 🎬 Netflix Clone

A responsive Netflix-inspired frontend website built using HTML5 and CSS3. This project recreates the look and feel of a streaming platform while focusing on responsive design, layout, and user interface development.

## ✨ Features

- Netflix-inspired homepage
- Responsive layout
- Navigation bar
- Hero/banner section
- Movie and TV show sections
- Movie thumbnails and content cards
- Hover effects
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
